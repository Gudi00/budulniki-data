# Будульники — данные о занятости БГУИР

`occupancy.json` — сжатый индекс расписаний всех групп БГУИР из открытого API [iis.bsuir.by](https://iis.bsuir.by/api/v1): кто, где и когда занимается. По нему приложение «Будульники» считает, сколько человек сейчас на парах (по факультетам, корпусам, курсам) и какие аудитории свободны.

Обновляется автоматически раз в неделю. Последнее обновление: 2026-09-28T09:37:04+03:00, групп: 421, пар: 15367.
